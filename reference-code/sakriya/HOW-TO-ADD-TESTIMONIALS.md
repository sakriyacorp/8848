# Adding Testimonials

## Normal way (after SHEET-SETUP-GUIDE.md is done once)

1. Person fills your Google Form (or you add a row in the sheet yourself)
2. Open the sheet → tick the **Approved** checkbox on their row
3. Live on sakriya.net within ~5 minutes. Newest first. Untick = removed.

Adding one yourself by hand: type directly into the sheet's Quote / Name /
Role / Category columns, tick Approved. Timestamp can stay empty.

## Photos for heavy hitters (optional)

1. GitHub → `public/images/people` → Add file → Upload files → `hector.jpg`
2. In the sheet's **Image** column for that row: `/images/people/hector.jpg`
3. Any full https URL to a direct image also works. Broken/missing image =
   gold initials circle, automatically.

## Rules

- Real people, real quotes, with their OK. Never invent one.
- 1–3 sentences read best on the wall
- Keep store-revenue quotes general — no dollar figures, no machine talk
- Ask permission before using someone's photo
